# 復習アプリ（アプリ本体）

授業の内容を4択で復習する、iPhone向けのWebアプリ（PWA）です。ホーム画面に追加すると、オフラインで動きます。

- 問題データはこのリポジトリに含みません。端末の「ファイル」から読み込みます
- 学習履歴は端末内（IndexedDB）にだけ保存します
- 問題データがなくても、動く系統のデモを試せます（データ管理の「動く系統を試す（デモ）」、または URL の末尾に `?demo`。記録には残りません）

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html`・`style.css` | 画面 |
| `js/app.js` | 画面と操作 |
| `js/logic.js` | 出題・復習間隔・段階解放・取り込みの計算 |
| `js/db.js` | 端末内の保存 |
| `js/grid.js` | 動く系統（1.5.0）の計算：時代・需要・損失・給電・周波数・故障・事故・お金・学習との結びつき |
| `js/gridui.js` | 動く系統の画面（地図・パネル・地点のメニュー・事故の問題・演出・状態の札・小さなグラフ・開発者モード・デモ・チュートリアル） |
| `js/griddev.js`・`js/gridmenu.js`・`js/gridart.js` | 動く系統の画面に依存しない部分（開発者モード・デモ／地点のメニュー・したことの表示・チュートリアル・演出と状態の札／町と発電所のアイコン） |
| `js/japan.js`・`js/gridjapan.js` | 日本列島（1.6.0）：地図の形と地点（`ツール/日本列島/make_japan.mjs` が書き出す）／始める町・エリアの開く順番・史実の線・出典 |
| `js/gridimg.js`・`img/grid/` | 動く系統の絵（番号 → 画像の場所）。変換スクリプトが書き換える |
| `sw.js` | オフライン用（アプリ本体をすべて端末に保存する） |
| `vendor/katex/` | 数式の表示（KaTeX 0.16.11、MIT License） |

地図の海岸線は Natural Earth（1:10m、パブリックドメイン。npm の world-atlas 2.0.2 から）を簡単にしたものです。主な島だけを描いています。

## 更新するとき

`sw.js` の `CACHE` と `index.html` の `APP_VERSION` の番号を上げてから公開する。番号を上げないと、iPhoneに保存された古いアプリが使われ続ける。
