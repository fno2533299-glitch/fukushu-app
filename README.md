# 復習アプリ（アプリ本体）

授業の内容を4択で復習する、iPhone向けのWebアプリ（PWA）です。ホーム画面に追加すると、オフラインで動きます。

- 問題データはこのリポジトリに含みません。端末の「ファイル」から読み込みます
- 学習履歴は端末内（IndexedDB）にだけ保存します

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html`・`style.css` | 画面 |
| `js/app.js` | 画面と操作 |
| `js/logic.js` | 出題・復習間隔・段階解放・取り込みの計算 |
| `js/db.js` | 端末内の保存 |
| `sw.js` | オフライン用（アプリ本体をすべて端末に保存する） |
| `vendor/katex/` | 数式の表示（KaTeX 0.16.11、MIT License） |

## 更新するとき

`sw.js` の `CACHE` と `index.html` の `APP_VERSION` の番号を上げてから公開する。番号を上げないと、iPhoneに保存された古いアプリが使われ続ける。
